Install as a Chrome extension

Replace your New Tab page with the Quote Board — every new tab becomes a calm, fullscreen space for your own quotes.

Quote Board — Chrome Extension Unpacked extension package (.zip)
Download .zip
Why not just the Chrome Web Store? This extension isn't published there yet, so for now it installs the developer way — a few extra clicks, but completely safe, and it's the same process any Chrome extension starts with before it's published.
1
Unzip the download, then open the extensions page

Unzip the file you just downloaded — you'll get a folder called "extension". Then type chrome://extensions in Chrome's address bar and press Enter.

2
Turn on Developer mode

It's the toggle in the top-right corner of the Extensions page.

3
Click "Load unpacked"

Three new buttons appear once Developer mode is on — click the first one.

4
Select the unzipped "extension" folder

Pick the folder itself (not the .zip file) — the one you unzipped in step 1.

5
Done — open a new tab

The extension card appears in your list. Make sure its toggle is green/on, then open a new tab to see your board.
